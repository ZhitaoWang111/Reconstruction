文件数据层级包含的信息
*.sens时序观测
  • JPEG 编码的彩色图像
  • zlib 压缩的 uint16 深度图
  • 每帧 4×4 camera-to-world 位姿

  • 相机内外参、分辨率、压缩方式和 depthShift

  • 场景类型 sceneType

Before you use it

三个容易踩坑的地方

文件都已通过结构与 CRC 检查，但“文件齐全”不等于各字段可以不经转换直接混用。

A

先统一坐标系

网格和轨迹进入评测或可视化前，确认是否需要应用 axisAlignment。重复应用或完全忽略都会造成朝向/位置错误。

#

以真实流为准

本地 scene0001_00 与 scene0005_01 的 TXT 声明帧数各比对应 .sens 多 1。遍历时应读取 `.sens` 文件头的 frame count。

ID

不要混淆三种编号

segment ID、objectId 与 semantic label 是三套不同索引。需要通过 segs.json → aggregation.json → labels TSV 逐层关联。
