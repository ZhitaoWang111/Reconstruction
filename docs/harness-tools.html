本次 harness_window01_v3 为使用当前 prompt 从头重跑的 30 帧、6 窗口记录，保存后的请求、响应和工具记录未做字段迁移。
旧实验字段迁移说明（2026-09-22，仅适用于历史实验）：历史观测的 label 已改为 category_label，物体与 create 参数的 label 已改为 object_label；物体编号已统一从旧前缀迁移为 Object+数字；类别判断与处理结果未重新推理。历史 prompt 中的编号表述同步迁移，代码哈希快照仍保留当时版本，来源哈希按迁移后的日志计算。
原始记录来自已保存的运行日志；标注“阅读解释”的段落是根据日志补充的说明，不是模型原话。操作标题和阅读解释中的物体编号统一显示为 Object 001 形式；历史记录中的物体编号也已迁移；其余参数、模型理由和错误保持原有内容，方便核对。本页只读取快照，不执行工具或调用 API。

记录边界与来源

不同实验不混为一次运行。窗口内按运行标识、call 序号、重试序号展示；同一重试中的响应、元数据和错误归为一组事件，不推断未记录的时间。

request.json 是原程序保存的脱敏请求：图像字节已经被替换为占位符。本页保留占位符，不用演示图片补成“原始输入”。response.json 是程序保存的响应对象，不是原始 SSE 网络报文。模型未输出文字时标记为空，不补写思考过程。

JSON 字符串参数可解码展开阅读；对应的原始字段与文件链接仍保留。没有提交成功记录就不推断成功。该页面为生成时快照，新运行后需重新执行 python3 docs/assets/harness-records/build_records.py。
