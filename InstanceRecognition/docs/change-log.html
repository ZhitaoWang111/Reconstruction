4d95fa9 标签不再承担区分个体的职责 2026-11-04
要解决的问题
  • P6 加了一条规则「label 必须能指向唯一一个物体」，模型据此把「是哪一件」塞进 label。
  • 结果标签平均 1.8 词涨到 4.3 词，最长 13 词，41% 含相对位置短语（left shoe beside console）。
  • 这类标签是地址，所指物体一旦被 merge/relabel 就失效；也不符合下游 handoff 契约要的短类别词。
  • 追溯发现：P6 那条规则的目标（压掉重名）是真实的，v9 的 17 个同名物体却全是正确命名——四只鞋、三处插座、四幅画。
改动方向
  • 把「是什么」与「是哪一个」拆开：label 只说类别，1–3 词。
  • 同类多实例允许同名，区分交给 object_id；指名道姓写进 reason。
  • 保留 P6 里对的半句：一个 Object 是一件实体，不是一类。
  • 代码零改动——state.py 从不检查标签唯一性。

7331041 deferral 不再随每个窗口重发 2026-11-04
要解决的问题
  • listing() 把全部无主观测塞进首条消息：末窗 532 条 defer + 18 条 exclude，149 KB。
  • 其中 exclude 是已结案的决定，语义上不是待办；defer 也没有出路—— 一条观测的 mask 只在自己那窗出现，召回需要按 id 主动 assign 历史观测，500 帧里发生 0 次（8,909 条 assign 全部指向本窗）。
  • 532 条 defer 被重新认领的也是 0 条。清单只增不减，唯一读者是渲染。
改动方向
  • 停止广播，不是禁止：defer 仍是合法状态，覆盖率检查照旧，state.json 记录全留。
  • 下游消费者改名：summary 拆成 deferrals / excluded，页面文案改「已搁置」。
  • prompt 里「以后还能认领」的承诺一并改掉——它从未兑现。
