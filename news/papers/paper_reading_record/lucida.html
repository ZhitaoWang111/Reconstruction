1. 研究背景和动机

Lucida 关注可组合真实到仿真的场景建模：把真实室内场景恢复成一组完整、可编辑、可单独操纵的 3D object assets，并按观测场景重新摆放。它不是 NeRF/3DGS 式整体重建，而是要服务机器人仿真、embodied AI、AR/VR 和内容编辑。

作者认为现有 parse-generate-place 管线的难点在于每一步都假设了真实采集中很难得到的输入：parse 需要准确实例几何或点云，generate 需要无遮挡、居中的物体视图，place 又假设生成资产与真实观测几何高度一致。遮挡、重复家具、深度噪声和生成资产形状偏差会逐步放大误差。

Lucida 的思路是保留“解析-生成-摆放”顺序，但重新分配精度要求：前面只提供可靠的多视角证据和粗初始化，把高精度对齐推迟到最后的闭环 9-DoF 放置阶段。

2. 研究方法

整体管线

输入为 posed RGB-D observations，输出为 editable object-level replica。每个实例节点带有证据包 Eo={Vo, Mo, Po, bo, co}：多视角图像证据、mask/box、局部点云、代表性 3D box 和类别/指代描述；图边编码 support、containment、adjacency 等空间关系。

Multi-view object-centric scene parsing

  • 几何感知关键帧选择：用共视性和时间距离控制冗余，选出覆盖更有用的 keyframes。
  • 对象发现与跨视角分组：VLM 识别物体实例，3D detector 预测 box，再按语义和几何一致性聚合。
  • full-sequence evidence consolidation：关键帧不足时，用 video segmentation/tracking 向邻近帧传播，并用代表性 3D box 和几何一致性过滤。
  • relation-aware scene refinement：修正错误 merge/split，补找缺失支撑物，提升场景级一致性。

Amodal object asset generation

由于真实采集下单物体点云常被遮挡，Lucida 不直接做点云补全，而是从 Eo 中挑选可靠且互补的多视角证据，用 Set-of-Mark 标注目标，VLM 组织 anchor/reference 和编辑指令，先合成无遮挡物体中心图像，再用 image-to-3D model 生成完整资产。

GizmoAct：把 pose estimation 做成 GUI 交互

GizmoAct 是一个 VLM policy，把 3D grounding/pose refinement 建模为多轮 3D editor gizmo 操作。它从粗 pose 开始，在渲染观测中反复调整 rotation、translation、anisotropic scale，最多 12 步，并自行判断何时停止。这个设定允许资产形状与真实物体不完全一致时仍逐步对齐。

它的核心 action 是 update_pose 和 stop，并通过 switch_obs、permute_axis 处理大旋转误差。update_pose 不预测绝对 pose，而是在当前 gizmo 局部坐标系中给出 ZXY 旋转增量、按对象尺寸归一化的平移增量和相对尺度增量；permute_axis 覆盖 24 种轴对齐重定向，把粗旋转留给一次离散动作处理。

GizmoAct 训练

训练分为 SFT 和 RL 两步。SFT 使用 synthetic expert trajectories，每条样本包含 evidence bundle、生成或给定的 object asset、扰动初始 pose 和隐藏目标 pose；轨迹在与推理相同的可执行环境中 rollout，并打包成多轮图像-文本对话。

SFT 数据混合来自三类来源：Populated 3D-FRONT 提供干净室内几何和密集桌面布局；FoundationPose 风格数据强调随机光照、任意朝向、重遮挡和资产/图像外观不一致；CA-1M Objects 提供真实噪声点云、长尾类别和由 SAM 3D 生成且人工对齐到 LiDAR 的资产。expert policy 按“先旋转、再平移和尺度”的顺序修复，并注入错误动作，让模型学习从自己造成的坏状态中恢复。

RL 使用 GRPO 在同一环境中做 online rollouts。reward 只看最终状态：用 generalized 3D IoU 衡量平移/尺度，用 geodesic rotation error 衡量旋转，并离散成 bad、coarse、success、excellent 等级；只有两轴同时达到 success 才给正奖励，正确 stop 还有额外奖励。由于旋转误差会误罚对称等价姿态，论文把 symmetric objects 排除出 RL 训练。

物体 pose refinement

在 R2S-Object、CA-1M、ADT 上，GizmoAct 与 Any6D、SAM 3D、RecGen 比较 ADD-SB、阈值成功率和 3D IoU。max-4-view GizmoAct 在 R2S-Object 达到 ADD-SB 0.017、ADD-SB@0.05 92.0%、3D IoU 0.719；CA-1M 达到 0.021、83.4%、0.607；ADT 上单视图 ADD-SB 最低为 0.020、ADD-SB@0.1 最高为 98.3%，max-4-view 的 ADD-SB@0.05 和 3D IoU 最好，分别为 90.0% 和 0.670。

完整场景重建

R2S-Scene 上，Lucida 用同一估计深度图进行 metric scene placement。相比 SAM 3D，scene-level CD 从 0.022 降到 0.010，Scene F-Score 从 0.794 提升到 0.924，BBox IoU 从 0.396 到 0.495；object-level CD 从 0.038 降到 0.034，F-Score 从 0.704 到 0.736。

消融与边界

解析模块三项消融都会降低 R2S-Scene mAP 和 scene F-Score：uniform keyframe selection 让 mAP 从 0.597 降到 0.516；去掉 full-sequence evidence consolidation 降到 0.535；去掉 relation-aware scene refinement 降到 0.526。GizmoAct 的 RL 训练若匹配 Boxer 初始化分布，也优于随机扰动训练。

GizmoAct training 消融还说明 RL 的主要收益在 difficult cases：110 个非对称 hard subset 上，GizmoAct (RL) 的 rotation error 为 20.98°，优于 GizmoAct (SFT) 的 45.19° 和 SFT no-context 的 27.62°；Rot.@5° 提升到 67.3%，高于 52.7% 和 60.9%。

公平性边界上，scene detection 中所有方法收到相同 target instance prompts；object pose 中 Any6D 和 GizmoAct 使用同一 generated asset，而 SAM 3D、RecGen 是联合估计 shape 和 pose；scene reconstruction 中 SceneGen 和 SAM 3D 接收相同 reference image 和 instance masks，Lucida 使用多视角 evidence。结果因此主要比较“证据组织 + 闭环 grounding”的收益，不等同于比较不同 3D asset generator 的上限。

局限上，Lucida 依赖 posed RGB(-D) observations、VLM、image editing、image-to-3D、SAM 3D/Seed3D 等基础模型与人工标注的 benchmark。生成资产的遮挡面属于 amodal completion，不是观测事实；论文也未把材料、摩擦、关节、动力学或机器人策略训练作为已验证输出。因此它是强 composable real-to-sim modeling pipeline，而不是端到端单模型或完整物理数字孪生。
