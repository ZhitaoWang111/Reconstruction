02版本：v1 → v2

2026-11-10 应下游要求补充了相机内参、外参约定、floor_z 和轴对齐矩阵，并把每个关键帧的 camera_to_world 改为必填。 v1 目录缺这些字段，过不了新的 check.py，所以版本号升为 handoff/v2。

  • 对读取方向后兼容：v1 的字段一个没删、取值不变，628 个点云 / 图片逐字节不变。只读旧字段的代码不用改；ObjectGeneration 的 handoff_io 只检查前缀 handoff/，已实测能读 v2。
  • 对生产方不兼容：v1 目录在新 check.py 下报错（缺 camera、floor_z、axis_alignment、camera_to_world）。
  • 下表里标“v2 新增”的就是这次加的字段。

04使用时注意

  • 内参只能用 manifest 里这套。Video2PointCloud 抽帧 manifest 里的 intrinsic_color 来自 .sens 文件头，和 2D 标注有约 6 px 竖直偏差。两套内参的实测对比见 ScanNet/docs/raw-data-notes.md 第 3 节。
  • 不要叠加 colorToDepthExtrinsics。camera_to_world 直接就是彩色相机的位姿，标注按它 (0,0) px 对齐。
  • bounds 不是尺寸，扫描最低点不是落地点。nightstand obj_0050 扫描最低 0.21 m、stool obj_0031 0.13 m，实际都立在地上；用 floor_z 判断时要考虑下半截没扫到。
  • 相机位置用 camera_to_world[:3,3]，不用 camera_center。
  • 两套帧编号。本文件的 seq 属于 500 帧采样；harness 当前用的 100 帧 source 另有自己的 seq，跨数据对齐用 source_frame_id。
  • 下游已生成的产物仍有效。11-10 的更新只新增字段，原有字段和 628 个点云 / 图片逐字节不变；所以 assembly_handoff 里 matches_generation_input=false 不影响资产。
