01一个窗口的初始输入按 inputs.py 的组装顺序

一个窗口的初始输入 ├── 0. system 消息 prompt.txt 全文（P7），每个窗口相同 │ └── tools 参数：inspect_observations / inspect_object / propose_update / commit_update │ ├── 1. 窗口状态与全局几何 一条 text 块，最先发送 │ ├── window [first, cutoff]、max_calls │ ├── state tools.listing() │ │ ├── version │ │ ├── objects：每个 Object 一条 │ │ │ ├── id、object_label │ │ │ ├── created_at、status（恒为 provisional） │ │ │ ├── label_history 发生过 relabel 才有 │ │ │ └── observation_count 只给数量，不给任何观测 id │ │ └── aliases merge 后的旧编号映射 │ └── spatial_candidates_policy 一句说明：规则参考 1105-v1 第 2 项 │ ├── 2. 当前观测 每帧 5 个块，按帧顺序发送 │ ├── text：sampled_sequence + observations，每条观测一条记录 │ │ ├── id（seq:instance）、seq、source_frame_id、instance_id │ │ ├── category_label 上游类别提示，不是物体身份 │ │ ├── bbox_xyxy、image_size_wh、overlay_color_rgb │ │ ├── point_count、centroid、bounds 反投影点云摘要 │ │ └── spatial_candidates：至多 15 个 │ │ └── object_id、object_label、gap_m（第 5 百分位最近距离）、overlap（10 cm 内占比） │ ├── text「original RGB」 + 图：完整原始 RGB │ └── text「full-frame colored mask overlay」 + 图：彩色 mask + 编号 + 2D bbox │ └── 3. 历史访问说明 最后一条 text └── 只有档案和全局几何；历史代表观测的元数据和图片要调 inspect_object / inspect_observations 取
高亮的两处是初始输入里全部的几何信息：centroid/bounds（观测点云摘要）和 spatial_candidates（相邻物体候选）。 只写审计、不发给模型的：每个物体的代表观测（representative）和 spatial_candidates 原表，存在 window_inputs/NNNN_context.json。
