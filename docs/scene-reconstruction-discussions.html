跨帧看见的，究竟是不是同一个物体？

本轮聚焦物体身份、位置与类别的一致性，不把“得到点云”直接等同于“得到可交互资产”。

原问题 · 用户原文

我们来开放式的讨论一个问题，就是我想做的是一套能只接收视频作为输入，把视频中的场景重建成为可交互的simready场景的算法。

这个算法面对的一个重要的问题就是跨帧一致性的问题，同一个物体，在视角差别很大和拍摄时间差别很大的两帧中被拍到，很可能被赋予不同的类别名，因而被识别成不同的两个物体。

另外靠的相近两个同类物体也很在聚类时，因为类别一致而被聚类为一个物体。所以如何从视频中正确识别出所有物体，确定他们的位置和类别是个很困难的问题。你有什么思路？

核心判断：先建立身份，再统一名字

增量建档 ＋ 全局纠错，最后生成可交互资产。

模型每一帧给出的 mask 和类别，只是一条“看见了什么”的观测。系统需要另外维护“它是谁”的物体档案，让同一个物体可以积累不同名称，不同物体也可以拥有相同类别。

这不要求在线立即做最终决定。先允许临时身份和不确定关系，视频结束后再利用全部视角修正。

重新看这个问题，类别名变化不一定是错误：chair 和 armchair 可能只是描述粒度不同。真正需要避免的是把“名称变化”直接变成“物体数量变化”。

因此要分开四件事：类别名是属性，帧内 mask ID是观测编号，临时物体 ID是关联假设，全局物体 ID才代表最终确认的实体。

一个例子：并排摆着的两把椅子

假设视频拍到了左椅子 A 和右椅子 B。下面是示意，不是当前实验的统计结果。

同物可以异名，异物也可以同名；归属应由观测证据决定。
观测模型给的名称系统应该怎样处理
开头看见 A 正面chair建立临时档案 A，保存 mask、位置与来源帧。
很久后看见 A 侧面armchair若几何和中间视角支持同一物体，就归入 A；不因名字变化新建资产。
同一画面清楚看见 BchairA、B 是两个完整物体的证据支持分开；不因同类且靠近就合并。
只看见难以归属的椅背chair证据不足时暂不归属，等待其他视角；不强行猜 A 或 B。

理想结果是两个物体 ID、两份各自的几何、各自的类别证据，而不是按名字生成三个模型，或把两把椅子拼成一个模型。

建议方案：聚合观测，不直接按类别聚类点

  1. 01 · 收集逐帧观测

    图像、mask、局部几何、名称与置信度。

  2. 02 · 关联临时物体档案

    更新已有物体，或建立待确认的新身份。

  3. 03 · 纠错全局合并与拆分

    检查长时间回访、错误连边和类别冲突。

  4. 04 · 生成独立 SimReady 资产

    身份稳定后，再补几何和交互属性。

  1. 先建立统一空间中的观测。从视频估计相机与几何，把每张 mask 对应的可见表面放到同一坐标系；保留原帧、像素对应和不确定性。几何重估时应能重新投影，不能把早期漂移永久焊死。
  2. 再判断两次观测是否来自同一个物体。先按空间关系检索候选，再结合表面对应、多视角一致性、时序连续性和图像外观。类别只作辅助证据，不作为必须相等的条件；外观相似也不能单独证明身份。
  3. 用全视频证据纠正临时关联。保留原始观测和每次合并／拆分理由，允许撤销。不能因为 A 连 B、B 连 C，就在存在冲突时把 A、B、C 全部合成一个物体。
  4. 按物体融合位置、几何与语义。用多视角支持的表面估计位置和范围，而不是用单帧可见片段的质心当物体中心。类别按不同视角的证据加权，保留原始别名和候选细分类；连续相似帧不应重复计成大量独立证据。
每个物体档案至少保存

全局／临时 ID · 来源帧与 mask · 已观测表面点云 · 位置与范围 · 类别候选及置信度 · 合并／拆分历史。

这是建议的数据表达，不代表这些字段已经全部实现。最终补全网格应与真实观测点分开保存。

最重要的规则：同一、不同、暂时不知道

支持同一
在误差容许范围内有一致的三维表面对应；其他视角能把局部观测连接为同一整体；外观与可见性也相容。要多条证据互相支持。
支持不同
多个可靠视角清楚显示两个独立完整物体，或位置／表面归属存在难以解释的冲突。空间相近和类别相同不能抵消这些证据。
暂时不知道
看不到共同表面、严重遮挡、几何质量差或外观过于相似。没有重叠不等于不同；没有冲突也不等于同一。

特别注意：同帧的两个 mask 可能是重复检测，或“椅子／椅背”这样的整体与部件；一张大 mask 也可能错包两个物体。因此不能机械地把同帧不同 mask 判为不同物体，也不能把一次重叠判为同一物体。

第一版宜优先控制误合并：把两个物体混成一个，后面的形状和资产生成都会受污染；暂时多留一个待确认档案，通常更容易回退。但必须同时报告未解决比例，不能靠“全部不知道”获得表面的高准确率。

下一步：先验证“认对物体”，不要急着生成资产

建议先做一个小型关联诊断，再扩展到整个场景；本轮仅记录实验设计，不运行新聚类。

  1. 选困难样例。从已有场景选少量关键帧和 20–50 对 mask 观测，覆盖同物异名、相邻同名、长时间回访，以及重复／部件 mask。人工标为同一、不同或证据不足。
  2. 比较最小方案。对比“仅几何关联”与“几何＋多视角证据”，再看加入外观是否真正有帮助。先不把多个大模型堆在一起，也不预设某个相似度阈值天然正确。
  3. 记录可检查的结果。每一对都输出支持证据、反对证据和决策。留出部分样例不参与调阈值；分别报告误合并、误拆分和未决比例。对确定给出的 same／different 判断统计错误，人工也无法判断的样例单列。
  4. 再检验全局聚类。配对判断通过后，仍要检查是否出现错误连边造成的大簇、同一物体被拆成多个 ID，以及物体点云混入邻居表面。配对正确率高不等于全局身份正确。
与现有实验的连接

目前这份反投影结果有 500 帧、6,795 个原始 mask 观测，没有跨帧融合和类别归并。它可以作为关联实验的输入，但“观测数量”不是“物体数量”。

依据：投影报告 · 离线点云检查页

这套思路能解决什么，还不能保证什么

  • 先限定静态室内扫描。第一版以完整物体为身份单位；动态物体需要额外区分物体运动与相机运动，柜门／抽屉等部件身份和关节层级留到后续。不能只靠固定空间位置追踪移动物体。
  • 视频没有看到的内容，不能当作已恢复。漏检的物体不会靠聚类凭空出现；相反两面没有连接证据时，身份也可能无法确定。隐藏表面补全属于带先验的推测，不是观测真值。
  • 只输入单目 RGB，不代表绝对尺度可保证。几何本身存在尺度歧义；学习到的米制深度或尺寸先验可以估计尺度，但不是可验证的物理保证。若引入已知尺寸、深度或其他传感器，应明确说明输入假设已经改变。
  • 实例点云不等于 SimReady。还需要独立网格、碰撞体、支撑关系、合理尺度，以及任务需要的关节和物理参数。尤其摩擦、质量和未展示的关节运动，不能从普通扫描视频直接保证，需要先验、假设或额外验证。
GT 边界必须单独记录

当前点云使用 GT 修正的 AMB3R 几何。可先用它隔离变量、诊断关联问题，但它仍可能有局部几何误差；后续必须在不使用 GT 修正的 RGB 重建上重测。前者通过，不能证明整个系统已满足“只接收视频”的目标。

参考思路，不直接照搬输入假设

  • MaskClustering · 官方项目：借鉴多视角共识与 mask 图聚类。官方代码说明的输入是 RGB-D 扫描与重建点云；它不是从纯 RGB 视频完成几何和 SimReady 的整套方法。
  • ConceptGraphs · 官方项目：借鉴对象级地图与跨视角增量关联。原方案使用带位姿的 RGB-D 图像；我们需要另行解决 RGB 几何、误差传播和可撤销身份关联。

上面的组织方式与实验顺序是本轮方案建议，不是对已有论文效果的复现声明，也不是已验证的完整系统。

第一轮留下的判断

不要让类别名决定物体身份；让跨视角证据维护可纠错的物体档案。

暂不采用“同类别＋距离近就合并”，也不在逐帧阶段生成最终资产。下一轮应重点讨论：关联证据如何量化、何时允许合并，以及如何发现并拆开错误合并的物体。

同一个马桶，为什么变成了 potty、water tank 和 chair？

本轮从三张实际截图出发，讨论如何得到“一份物体点云＋一个稳定类别”，不修改原始检测结果。

本轮问题 · 用户原文

我们从一个具体的问题出发，你可以看一下tmp/下的3张图，房间中的同一个马桶在相邻3次识别中被打上了不同的语义标签，对于这种情况，我们如何使用点云和2D Mask，在下一步处理的时候能正确定位物体的类别标签和对应的占据点云？

先看清问题：不仅异名，还拆成了部件

截图来自 tmp/109.png–111.png，已保存独立副本，可点击放大。按帧内 ID 和类别与本地 manifest匹配，候选源帧为 1218 / 1229 / 1241（sequence 109 / 110 / 111）；这是匹配推断，尚未逐像素确认。截图文件名不是原始视频帧号，类别前的 ID 也仅在各帧内有效。

建议：先认定是同一物体，再确定它叫什么

不按名字合并；按跨帧表面对应建立物体 ID。

chair 不应自动产生第二个物体，water tank 也不应被当作 toilet 的同义词。

  1. 关联整体观测。取每张 mask 对应的已有世界坐标点，比较共同可见表面的对应，而不是只比中心距离。再投回另一帧：既要落入对应 mask，也要与该处深度相符。这样，109 的 potty 和 111 的 chair 才有依据归入同一个物体候选。
  2. 区分整体与部件。若 110 的水箱点被其他视角的整体马桶观测稳定包含，就记录“水箱属于这个马桶”，坐便器区域同理。不能因为两块点相邻就合并，也不能因为同帧有两个 mask 就断定是两个独立物体。单张大 mask 可能包错，需更多视角复核。
  3. 形成物体点云。将已关联观测映射到共享体素或表面邻域，合并重复采样；由多个有效视角支持的点组成稳定表面。边缘、只见一次或归属冲突的点单独保留为待确认，不直接混入最终点云。遮挡和漏检不计为反对票，相邻近似视角也不重复算作独立证据。
  4. 最后确定类别。挑选清晰、视角不同的 RGB＋mask 裁剪，再识别一次或人工核对。几何能支持“是同一个”，却不能单独证明“叫马桶”。本例用户已给出马桶这一人工参照；自动流程仍应复核 toilet，把 chair 记为误判证据、water tank 记为部件描述，而不是对三帧简单多数投票。
展开：关联和点归属具体怎么判断？

双向看覆盖。分别计算“A 的可靠可见点有多少得到 B 的 mask／表面支持”与反方向的比例。双向高覆盖支持同一表面观测；只有小块被大块覆盖，提示部件／局部观测候选，而非立即合并。可见共同表面太少时记为未知，不能用少数点的高比例作结论。

再看多视角归属。每个体素保存来源帧、mask 和物体候选的支持／冲突证据。只在视野内、未被遮挡且深度可信的位置检验；只投到 2D mask 内还不够。没有检测到该物体不等于背景，若有可靠的其他实体表面争用该点，则保留冲突。体素尺寸和匹配半径应按局部几何误差校准。

不丢原始数据。使用逐帧 NPZ 中的 mask 点，而非仅用展示用的抽样全局 PLY；沿用 mask_bits 的重叠归属及原始标签，另存派生物体结果。跨帧点不是天然共享同一索引，需要空间对应；重投影还需与点云一致的相机位姿、深度与图像裁剪，不能混用未修正的坐标。

这个例子希望得到的结果

示意档案：object_001 → 候选类别 toilet → 水箱＋坐便器的已观测表面点云；水箱保留为部件，不另算一个完整物体。

定位：记录稳定表面的空间范围框；其中心仅用于定位展示，不宣称是完整马桶的真实中心。原始标签、来源帧／mask 与待确认点都可追溯。

这是目标结果，不是已算出的关联。这里的“占据点云”只指已观测表面，不包含未见背面、内部实心体积或完整碰撞体。水箱上的卷纸、旁边的墙／地面不能因被 mask 带入就算作马桶；若所有视角都把卷纸与马桶粘在一起，仅靠投票也分不开，需要局部重新分割或保留未决。

下一步只做这个马桶的小实验：复核这组三帧与原图的对应，补几张有不同视角的观测，展示候选关联、水箱部件关系，以及稳定／待确认／冲突三类点。先验证没有混入邻物，再扩大到整个房间。

相较第一轮的推进：把“先身份、后语义”具体化为“整体观测与部件观测分开关联”。当前 GT 修正 AMB3R 点云仅作诊断输入，仍有局部误差；三张相邻截图本身不足以证明三维关联和类别已正确。

思路参考：MaskClustering 官方项目用其他视角的共同包含关系构建 mask 关联证据。本轮的部件关系、未决点与类别复核是针对本例的方案建议，不是该方法已保证解决的能力。
