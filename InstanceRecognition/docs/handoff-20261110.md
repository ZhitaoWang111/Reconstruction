## 四、任务一（优先级最高）：实现 1105-v2 自动淘汰评分改进

### 背景

v14 中 Object064（电视柜）只 hold 了下半部分的门板，上半部分两条被自动淘汰。根因：当前评分 = 0.5×点数 + 0.5×视角，视角项有两个 bug 导致得分几乎全是 0，实际上是纯点数排序，上柜门点数偏少所以被淘汰。

### 两个 bug（`state.py:_score_holds`）

1. **视角方向 bug**：用的是 `camera_pos / |camera_pos|`（相机到世界原点的方向），应该是 `camera_pos - midpoint(c_i, c_j)` 的方向（c 是每个观测自己点云的质心，midpoint 是两个观测质心的中点）。
2. **参照集合 bug**：`_auto_evict` 把已持有观测放进 `existing_positions`（参照集），然后又让它们参与评分，导致每条 held 观测和自己的方向比，视角得分必然为 0。正确做法：S 从空集开始，held 和 new 一起竞争，greedy 逐轮选入 S。

### 新的四项评分公式

```
score(i | S) = w_a·A + w_p·P + w_v·V(i|S) + w_c·N(i|S)
```

- **A**（mask 占比）= `mask_pixels / (W×H)` ÷ 候选中最大值
- **P**（点数）= `point_count` ÷ 候选中最大值  
- **V**（视角多样性）= `f(min_{j∈S} θ_ij)`，其中 `θ_ij = ∠(t_i − m, t_j − m)`，`m = (c_i + c_j)/2`，t 是相机位置（camera_to_world[:3,3]），c 是观测点云质心
- **N**（新增表面）= 观测 i 的点中，离已选集合 S 点云超过 10 cm 的比例

S 从空集开始，每轮贪心选总分最高的加入 S，共 5 轮（HOLD_LIMIT=5）。第 1 轮 S 为空：V=0，N=1，只由 A 和 P 排名。

**确定的权重**：`w_a : w_p : w_v : w_c = 1 : 1 : 1 : 1`，视角换算 `f(θ) = (1 - cos θ) / 2`，新增表面半径 10 cm。

### 实现前需要注意

- 点云质心（c）：从 `data.items[oid]['centroid']` 读取（已有字段）
- 相机位置（t）：从 source npz 文件 `frames/{seq:04d}.npz`['camera_to_world'][:3,3] 读取（参考 `docs/debug/evict-weights/build_data.py:86`）
- 新增表面计算：需要 KDTree，用 scipy.spatial.cKDTree；半径 0.10 m（10 cm）
- N(i|S) 在 S 为空时 = 1.0（所有点都是新增表面）

### JS 参考实现

`docs/debug/evict-weights/algo.js`：`select(data, cfg)` 函数是完整的 greedy 4-term 选择逻辑，和 `newSurface(hist, selMask)` 一起，可以直接对照着写 Python。注意 JS 版用的是预计算好的 coverage bitmask（browser 里没法做 KDTree），Python 版直接算即可。

## 五、任务二（需要用户决策后才能动）：SAM 分割粒度问题

### 背景

Object064 在单帧里出现 11 个独立的 `cabinet` mask，原因不是 GPT 的问题，而是 SAM 3.1 文本 prompt 粒度问题：

- GPT 正确地输出了一个 category entry：`"cabinet" / sam_prompt: "cabinet"`（prompt 明确要求 whole objects over parts）
- SAM 3.1 对 `"cabinet"` 文本 prompt 返回多个高置信度 mask（每块门板各一个）
- `sam31_segment.py` 对同一 text prompt 的多个 mask **没有任何合并/去重逻辑**（`cross_category_nms: False`）

### 两个候选修复方向

**方案 A — 后处理 same-category 合并**（`src/inference/sam31_segment.py`）  
对同一 text prompt 返回的多个 mask，检查 bounding box 重叠（IoU 或 包含关系 > 阈值），合并为 union mask。空间分离的真正独立实例（如两把椅子）不受影响。需要重跑 SAM，不需要重跑 GPT。

**方案 B — 更描述性的 sam_prompt**（`src/inference/prompts/prompt_en.txt`）  
允许/指导 GPT 把 sam_prompt 写得更具体，例如 `"large built-in cabinet unit with multiple door panels"`，引导 SAM 给出粗粒度整体 mask。需要重跑 GPT + SAM。

**注意**：Object064"只 hold 了下半部分"这个具体现象，主要是任务一（评分 bug）的问题。SAM 粒度影响的是"整个橱柜究竟是一个 Object 还是按门板分成多个 Object"，这是两个独立问题。用户在当前窗口末尾的问题是在问 SAM 粒度，但还没有决定要不要修、怎么修。

**下一步**：等用户决定方向后再实施。
