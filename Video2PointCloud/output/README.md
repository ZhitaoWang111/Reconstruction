# Generated artifacts

- `amb3r/`: AMB3R frontend and VO results. The downstream GT-corrected cloud is `amb3r/vo_uniform500/pointcloud_gt_corrected_rgb.ply`; use it together with `pointcloud_gt_corrected_evaluation.json`.
- `da3/`: Depth Anything 3 Nested and DA3-Streaming results.
- `mapanything/`: MapAnything results.
- `single_frame_depth/`: ten-frame single-image depth predictions and comparison.
- `visualization/`: directly openable interactive HTML bundle and screenshots.
- `reports/`: experiment reports.
- `ARTIFACTS.sha256`: checksums for the canonical uniform-500 artifacts.

Files under this directory are generated results or result documentation. Runner code lives under `../src/`.
